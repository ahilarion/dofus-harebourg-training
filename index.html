1. Confusion selon ta vitalité

Lue en début de tour (clic sur le cœur pour afficher le %). Le sort part tourné autour de toi.

Équivalents lus dans les envoûtements / le canal combat : 90° horaire = 270° anti-horaire = horaire π/2 = anti-horaire 3π/2 · 90° anti-horaire = 270° horaire = anti-horaire π/2 = horaire 3π/2 · 180° = π.

Les invocations que tu contrôles n'ont pas de confusion.

2. Mêlée

Chaque ligne de dégâts infligée depuis le càc d'un monstre fait tourner ta confusion de 90° anti-horaire (pour les sorts suivants du tour).

  • Le coup en cours respecte la confusion actuelle ; le décalage s'applique après.
  • Sort à 2 lignes au càc → −180°, à 3 lignes → −270° (= +90°).
  • Ex. : 90° horaire − 1 ligne = plus de confusion ; 90° horaire − 2 lignes = 90° anti-horaire.
  • Au-delà de 10 coups reçus, le monstre frappé au càc ne modifie plus la confusion.
  • Invocations / bombes qui frappent au càc comptent comme dégâts de mêlée.

Sort redirigé vers une case inexistante ou sans ligne de vue = échec critique (au càc : fin de tour).

3. Delock (état invulnérable)

  • Tour impair : chaque coup sur le Comte te téléporte symétriquement par rapport au Comte.
  • Tour pair : chaque coup téléporte le Comte symétriquement par rapport à toi.
  • Si une entité est sur la case d'arrivée (tour pair) : échange de place → le Comte perd son invulnérabilité.
  • L'allié échangé gagne +100 dommages pendant 1 tour.
  • Échange avec une invocation alliée → tous les alliés à ≤ 3 cases de la position initiale du Comte meurent.
  • Case d'arrivée bloquée (case noire, obstacle, hors carte) → combat perdu, toute l'équipe meurt.
  • Une téléportation par ligne de dégâts : un nombre pair de lignes ramène le Comte à sa case.

Placement : la case où te placer est le milieu entre le Comte et le partenaire d'échange. Il faut un écart pair sur les deux axes.

Une fois vulnérable, Stabilisation (ou un état pesanteur) l'empêche de bouger quand tu le frappes.

Sur le plateau, l'anneau doré du Comte pulse tant qu'il est invulnérable ; il se brise au delock.
